# Картинки Chord

Нарисованы по макету «Трубка + настройки» (Combo): тёмная тема, акцент `#6fb3a0`.

## Что в папках

| Папка | Зачем |
|---|---|
| `bmp/` | Для Windows. Win32 читает BMP сам, без библиотек. Каждая картинка уже лежит на своём цвете фона, так что прозрачность не нужна. |
| `png/` | Те же картинки, но с прозрачным фоном. Пригодятся для Linux (GTK) или если позже подключишь `stb_image.h`. |
| `svg/` | Исходники. Цвет или форму меняешь тут, открываются в браузере, Inkscape и Figma. |
| `logo/` | `chord.ico` — иконка окна, внутри все размеры от 16 до 256 px. `chord-logo-dark` и `chord-logo-light` — логотип со словом для README на GitHub (под тёмную и светлую тему). |
| `preview.png` | Все картинки на одном листе. |

Имена файлов: `кнопка_состояние`. Состояний три: `normal` (обычная), `hover` (под мышкой) и `pressed` (нажата).

У кнопок-переключателей по две картинки: `settings-on` — настройки открыты, `mic-off` — микрофон выключен, `screen-on` — экран показывается собеседнику.

Картинки нарисованы прямо на этих цветах. Если покрасить фон окна по-другому, вокруг кнопок будет видна рамка.

| Что | Где | Цвет | В C |
|---|---|---|---|
| рамка окна | 1 px по краю | `#2a2e33` | `RGB(0x2A, 0x2E, 0x33)` |

## Как подключить в Win32

1. Окно 340×560 со стилем `WS_POPUP`. В `WM_NCHITTEST` заголовком считается всё, что выше `y = 37`.
2. Каждая кнопка — обычный `"BUTTON"` со стилем `BS_PUSHBUTTON`, размер ровно как у её картинки. `BS_OWNERDRAW` не ставь: с ним Windows не присылает `NM_CUSTOMDRAW`.
3. Нужен манифест Common Controls 6, то есть строчка `#pragma comment(linker, "/manifestdependency:...")`. В `tasks.json` в конце команды `cl` допиши `/link /MANIFEST:EMBED`, чтобы манифест оказался внутри exe. Без манифеста Windows не сообщает, что мышь над кнопкой.
4. Картинки загружаешь один раз при старте:
   ```c
   HBITMAP bmp = (HBITMAP)LoadImage(NULL, L"assets\\bmp\\close_hover.bmp",
                                    IMAGE_BITMAP, 0, 0, LR_LOADFROMFILE);
   ```
   Путь считается от папки, из которой запущена программа (если собирать через Ctrl+Shift+B, это корень Chord). Если вернулся `NULL`, значит файл не нашёлся.
5. Рисуешь в `WM_NOTIFY`, когда пришёл `NM_CUSTOMDRAW`. В поле `uItemState` будет флаг `CDIS_SELECTED`, если кнопка нажата, и `CDIS_HOT`, если мышь над ней. Копируешь нужную картинку и возвращаешь `CDRF_SKIPDEFAULT` («я сам нарисовал, не трогай»). Копирование картинки в GDI всегда делается вот так:
   ```c
   static void draw_bitmap(HDC hdc, HBITMAP bmp, int x, int y, int w, int h)
   {
       HDC     mem = CreateCompatibleDC(hdc);   // временный «холст» в памяти
       HGDIOBJ old = SelectObject(mem, bmp);    // кладём на него картинку
       BitBlt(hdc, x, y, w, h, mem, 0, 0, SRCCOPY);
       SelectObject(mem, old);                  // возвращаем как было
       DeleteDC(mem);
   }
   ```
6. Иконка окна:
   ```c
   wc.hIcon = (HICON)LoadImage(NULL, L"assets\\logo\\chord.ico", IMAGE_ICON,
                               0, 0, LR_LOADFROMFILE | LR_DEFAULTSIZE);
   ```

Картинки нарисованы для Chord и распространяются под той же лицензией, что и сам проект (GPL-3.0).
